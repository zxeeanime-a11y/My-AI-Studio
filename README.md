# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/d5fda44f-08f4-4832-85c8-cb13711412dd

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

Uploaded videos are saved in the project-root `uploads/` directory after validation. The server creates this directory with writable permissions when it starts. To list uploaded videos, run `ls uploads` from the project root.
